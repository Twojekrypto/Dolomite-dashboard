# Borrow 24h and Table UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a source-backed 24-hour position-count change and polish Borrow summary/table hierarchy without changing the dashboard's Graphite + Gold identity.

**Architecture:** A small generated JSON file owns the rolling monitored-position count history and derived 24-hour comparison. `liquidation-preview.html` loads that optional file alongside the existing liquidation data, renders the metric and shared freshness labels, and applies route-scoped CSS for color and alignment.

**Tech Stack:** Python 3.11, static HTML/CSS/JavaScript, `unittest`, Node contract tests, GitHub Pages, in-app Browser QA.

## Global Constraints

- The monitored-position threshold remains exactly `$10` of collateral plus debt.
- The rolling history retains 72 hours and accepts a 24-hour baseline only within a six-hour skew.
- Missing history must render as unavailable, never as an invented zero change.
- Use existing `--up`, `--down`, `--gold`, and foreground tokens; add no dependency.
- Keep Collateral and Debt table columns fixed when widening Chain–Address spacing.
- Production deploys from remote `dolomite-dashboard` branch `master`.

```python
class TestPositionCountHistory(unittest.TestCase):
    def test_counts_the_same_ten_dollar_scope_as_borrow_ui(self):
        positions = [
            {"collateralUSD": 4, "debtUSD": 6},
            {"collateralUSD": 4, "debtUSD": 5.99},
        ]
        self.assertEqual(flr.count_monitored_positions(positions), 1)

    def test_builds_exact_signed_24h_change(self):
        now = 200_000
        previous = {"snapshots": [{"timestamp": now - 86_400, "count": 12}]}
        result = flr.build_position_count_history(previous, now, 9)
        self.assertEqual(result["change24h"]["change"], -3)
        self.assertEqual(result["change24h"]["baselineCount"], 12)

    def test_rejects_a_baseline_more_than_six_hours_from_target(self):
        now = 200_000
        previous = {"snapshots": [{"timestamp": now - 60_000, "count": 12}]}
        result = flr.build_position_count_history(previous, now, 9)
        self.assertIsNone(result["change24h"])
```

```python
MONITORED_POSITION_MIN_USD = 10
POSITION_COUNT_HISTORY_RETENTION_SECONDS = 72 * 60 * 60
POSITION_COUNT_24H_SECONDS = 24 * 60 * 60
POSITION_COUNT_24H_MAX_SKEW_SECONDS = 6 * 60 * 60

def count_monitored_positions(positions, min_usd=MONITORED_POSITION_MIN_USD):
    return sum(
        1 for position in positions
        if safe_float(position.get("collateralUSD")) + safe_float(position.get("debtUSD")) >= min_usd
    )
```
